# Irene (Yuhan) Zhang — Architecture Portfolio

An interactive architectural index: the home page is a table of contents of project tiles in three chapters (Academic, Professional, Independent). Each tile opens a project page of large drawings with a zoomable viewer. The resume page lives at `/resume/` and the CV downloads as a PDF.

Built with **React 19 + TypeScript + Tailwind CSS 4**. The build pre-renders every page to static HTML, so the site needs no server and runs on any static host.

---

## Quick start

```bash
npm install          # once
npm run dev          # http://localhost:4173 — rebuilds when you save (refresh the browser)
npm run build        # production site → dist/
npm start            # serve dist/ locally
```

Node 20 or newer is required.

## Folder structure

```
src/
  content/              ← everything you edit
    site.ts             name, tagline, categories, site URL, placeholder switch
    projects.ts         all projects, their sections, drawings and captions
    resume.ts           resume + About page text

  components/           Header, CategorySection, ProjectTile, ProjectGallery,
                        DrawingViewer, DrawingCaption, ProjectNavigation …
  pages/                IndexPage, ProjectPage, ResumePage, AboutPage
  lib/                  data model (types.ts), router, numbering helpers
  styles.css            design tokens (colours, type scale, grid) + Tailwind
public/
  images/<project>/     web images: <name>-800.webp, -1600.webp, -full.webp
  documents/            Yuhan_Irene_Zhang_Resume.pdf (the RESUME button), Irene-Zhang-CV-ZH.pdf
source-images/          drop original drawings here, then run `npm run images`
scripts/                build, dev server, image optimizer
```

## Content hierarchy

```
Category (site.ts)          01 / Academic Work
└─ Project (projects.ts)    01 Petra Ferro Winery           → /projects/petra-ferro-winery/
   └─ Section               Overview · Site Plan · Plans · Sections · Diagrams · Axonometrics · Renderings
      └─ Block (layout)     full · bleed · pair · grid · text-figure · text
         └─ Figure          image, title, type, scale, caption
```

Project numbers (01, 02 …) and figure numbers (FIG. 01.03) are generated from the order in `projects.ts`, so reordering renumbers everything automatically. Sections that a project doesn't list are simply not shown. Keep each project's sections in the order site-plan → plans → sections → diagrams → axonometrics → renderings (`kind` values); a section can take its own `title`, e.g. "Sections & Elevations".

## Common edits

### Add a drawing to a project

1. Put the original file in `source-images/<project-slug>/`, e.g. `source-images/petra-ferro-winery/ground-floor-plan.png`. PNG, JPG, TIFF or WebP all work; export large, around 4000 px on the long edge.
2. Run `npm run images`. This writes three WebP sizes to `public/images/` and records the dimensions.
3. Reference it in `projects.ts`:

```ts
{
  kind: "full",
  figure: {
    image: "petra-ferro-winery/ground-floor-plan",
    title: "Ground floor plan",
    type: "Floor plan",
    scale: "1:200",
    caption: "Optional sentence under the drawing.",
  },
},
```

**Block layouts**

| kind | use for |
|---|---|
| `full` | plans, sections, axonometrics: full content width, never cropped, capped to the screen height |
| `bleed` | renderings shown edge to edge |
| `pair` | two related drawings side by side |
| `grid` | 2 or 3 columns (`columns: 3`) |
| `text-figure` | a short explanation beside a drawing (`side: "right"` puts the text on the right) |
| `text` | text only |

Reorder drawings by moving blocks up or down in the list.

### Add a project

Copy an existing project object in `projects.ts`, give it a new `slug` (lower-case, hyphens) and set `category` to `"academic"`, `"professional"` or `"independent"`. The tile on the index uses:

```ts
cover: { image: "my-project/render", position: "50% 40%" },  // focal point of the crop
tile:  { span: 7, aspect: "16/10" },                            // 12-column grid
```

Tiles in a row should add up to 12. Leave `aspect` out on one tile and it stretches to match the height of the other tile in its row.

### Add a category

Add an object to `categories` in `site.ts`; it becomes a new numbered chapter on the index and a link in the top navigation (its `navLabel`, e.g. "Academic Works"). A category with no projects is hidden everywhere.

### Reserved "in preparation" tiles

Projects with `placeholder: true` show a hatched tile and a short holding page. Replace them with real content when ready, or set `showPlaceholders: false` in `site.ts` to hide all of them.

### Resume and CV

- Edit the page text in `src/content/resume.ts`.
- The RESUME button in the header opens `public/documents/Yuhan_Irene_Zhang_Resume.pdf` in a new tab, and “Download CV” on the resume page downloads it. To update it, save the new PDF over that file (same name, so nothing else changes). To use a different file name, change the first entry of `downloads` in `resume.ts`.
- The `/resume/` page shows the same content as text; keep `resume.ts` in step with the PDF when you change it. `Irene-Zhang-CV-ZH.pdf` is the Chinese CV.

### Colours and type

All colours are tokens at the top of `src/styles.css` (light and dark). The fonts are Inter Tight (titles), Inter (text) and IBM Plex Mono (figure numbers), loaded from Google Fonts.

## Deploy

> **This copy is live on GitHub Pages at <https://ireneyuyuu.github.io/>.** To publish changes, run `npm run deploy -- "what changed"`. The beginner guide is in [DEPLOYMENT.md](DEPLOYMENT.md).

**Netlify (simplest, no install needed):** this download already contains a built copy in `dist/`. Drag the `dist` folder onto <https://app.netlify.com/drop> and the site is live. After editing content, run `npm run build` and drag it again, or connect the repository; `netlify.toml` is already set up.

**Vercel:** import the repository; `vercel.json` sets the build command and the `dist` output folder.

**GitHub Pages:** push to GitHub, then under Settings → Pages choose "GitHub Actions". The workflow in `.github/workflows/deploy.yml` builds and publishes on every push to `main`. If the address is `https://<user>.github.io/<repo>/`, set `basePath: "/<repo>"` in `site.ts`.

After deploying, set `siteUrl` in `site.ts` to the live address. This adds canonical links, social preview images, `sitemap.xml` and `robots.txt`.

## Features

- Top navigation centred in the header: About · Academic Works · Professional Works · Contact. The category links scroll the index to that chapter (`/#academic`, `/#professional`) and stay underlined while you browse that chapter or one of its projects
- Index as an interactive table of contents; the whole tile is the link; hover zoom, crop marks and a "View project" label; all information stays visible on touch screens
- Pre-rendered pages with their own title, description and social preview image
- Real URLs with working back and forward buttons
- Drawing viewer: click any drawing, then scroll or pinch to zoom up to 200 % of the file's pixels, drag to pan, ← → to browse, 0 to fit, Esc to close. It loads the full-resolution file.
- Responsive images (800 / 1600 / full) with lazy loading and fixed dimensions, so nothing jumps while loading
- Sticky section navigation on project pages
- Keyboard focus states, skip link, reduced-motion support, light and dark themes
- Print stylesheet: printing the resume page produces a clean two-page CV
